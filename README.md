# Responsive Portfolio Website

## Overview

For this task, I designed and developed a personal portfolio website and enhanced it with responsive design using CSS Media Queries. The website showcases my background, skills, and projects while adapting seamlessly to different screen sizes. The goal was to create a layout that provides a consistent and user-friendly experience on both desktop and mobile devices.

## Features

- Responsive navigation bar
- Hero section with introduction
- About Me section
- Skills showcase using cards
- Projects section highlighting my work
- Mobile-friendly responsive layout
- Modern color palette and typography
- Built using HTML and CSS

## Technologies Used

- HTML5
- CSS3
- Flexbox
- CSS Media Querie
- Google Fonts (Oswald and Roboto Condensed)

## Responsive Design Implementation

I used CSS Media Queries to optimize the website for smaller screens. The responsive improvements include:

- Navigation menu adapts to mobile screens
- Hero section changes from a horizontal to a vertical layout
- Skills and project cards stack into a single-column layout
- Reduced spacing and resized elements for better mobile viewing
- Improved readability and usability across devices

## Color Palette

- #1C2230 – Primary Dark Navy
- #3D4A5C – Secondary Slate Blue
- #B7C3D0 – Soft Gray Blue
- #C46A5A – Accent Terracotta

## Outcome

This project helped me understand how responsive web design improves accessibility and user experience. By implementing CSS Media Queries and testing the layout across different viewport sizes, I created a portfolio website that functions effectively on both desktop and mobile devices.
